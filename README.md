# Helpful Perfumes

Helpful Perfumes is a Vite, React, and TypeScript storefront for perfumes, fragrances, attars, and decants in Bangladesh.

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

## Testing

```sh
npm test -- --run
```

The local perfume catalog is enabled through `VITE_PERFUME_CATALOG=true` and is served from `public/perfumes/`.
